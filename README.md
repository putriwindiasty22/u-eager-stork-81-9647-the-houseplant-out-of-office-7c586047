**The houseplant out-of-office** — the funniest out-of-office auto-reply a neglected houseplant would send, in 120 characters or fewer. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The joke is the plant's own grievance: unwatered since March, it has gone on strike, and it delegates urgent matters to the cactus — which gave up even earlier. Neglect, not decoration, drives the punchline.

The entry:

> Out of office: unwatered since March, so I'm on strike. For urgent matters, ask the cactus — it gave up in April.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
